# EC注文管理アプリ

## 概要

Pythonで作成したEC注文管理アプリです。

商品管理からカートへの追加、注文確定、注文履歴の確認・検索、注文キャンセルまでの一連の処理を実装しています。

また、JSONファイルを利用して商品情報と注文履歴を保存し、アプリを終了してもデータを保持できるようにしています。

## 主な機能

* 商品追加
* 商品一覧表示
* カートへの商品追加
* カート内商品の削除
* カート内商品の数量変更
* 在庫管理
* 注文確定
* 注文履歴表示
* 注文検索
* 注文キャンセル
* JSONによるデータ保存・読み込み

## 使用技術

* Python
* JSON
* Git
* GitHub

## 工夫した点

* 商品・カート・注文をそれぞれクラスとして分け、役割を整理しました。
* 注文確定時に商品の在庫を減らす処理を実装しました。
* 注文キャンセル時には在庫を元に戻す処理を実装しました。
* JSONファイルを利用して、商品情報と注文履歴を保存できるようにしました。
* カート追加時や注文確定時に在庫数を確認し、在庫以上の商品を購入できないようにしました。
