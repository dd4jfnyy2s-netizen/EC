# EC注文管理アプリ

## 概要

Pythonで作成したコンソール型のEC注文管理アプリです。

商品一覧から商品を選択してカートに追加し、注文確定、注文履歴の確認・検索、注文キャンセルまでの一連の処理を実装しています。

また、JSONファイルを利用して商品情報と注文履歴を保存し、アプリを終了してもデータを保持できるようにしています。

## 主な機能

* 商品一覧表示
* 商品の在庫管理
* カートへの商品追加
* カート内商品の削除
* カート内商品の数量変更
* 注文確定
* 注文履歴表示
* 注文検索
* 注文キャンセル
* JSONによるデータ保存・読み込み

## 使用技術

* Python
* JSON
* Git
* GitHub

## クラス構成

### Productクラス

商品の情報と在庫を管理します。

* 商品名・価格・在庫数の管理
* 商品情報の表示
* 在庫の追加
* 商品販売時の在庫減少

### Cartクラス

カート内の商品を管理します。

* 商品の追加
* カート内商品の表示
* カートの合計金額計算
* 商品の削除
* 商品数量の変更
* 在庫数を超えた数量の追加を防止

### Orderクラス

注文処理と注文履歴を管理します。

* 注文確定
* 注文IDの自動採番
* 注文履歴の表示
* 注文検索
* 注文キャンセル
* 注文キャンセル時の在庫復元

## データ管理

JSONファイルを利用してデータを保存・読み込みしています。

* `ec_order.json`：商品情報・在庫情報
* `order_history.json`：注文履歴

アプリ終了時にデータをJSONファイルへ保存し、次回起動時に読み込むことでデータを保持できるようにしています。

## 工夫した点

* 商品・カート・注文をそれぞれクラスとして分け、役割を整理しました。
* カート追加時と注文確定時の両方で在庫数を確認し、在庫以上の商品を購入できないようにしました。
* 注文確定時に商品の在庫を減らす処理を実装しました。
* 注文キャンセル時には、注文時に減らした在庫を元に戻す処理を実装しました。
* JSONファイルへの保存・読み込みを実装し、アプリ終了後も商品情報や注文履歴を保持できるようにしました。
* JSONから読み込んだ注文履歴について、商品名をもとに現在の商品オブジェクトと関連付けて扱えるようにしました。
* `try / except` を使用し、数字以外の入力などによるエラーを処理しています。

Pythonのクラス・オブジェクト指向、ファイル操作、JSON、データ管理、Git/GitHubなどの知識を実践的に学習するために作成しました。
